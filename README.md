# طراحان حرارتی (Tarahan Hararati)

میخوام یه سایت بسازم برای شرکت طراحی مهندسی فعال در زمینه تجهیزات حرارتی و مبدل های حرارتی



نمیخوام خیلی fancy باشه

ولی میخوام حرفه ای و مورد قبول و زیبا باشه

اسم و لوگو و رنگ هنوز مشخص نیست

سایت برای تمام افراد حاضر در صنعت ایران

طراحی و تولید مبدل های حرارتی صفحه ای

طراحی قالب پلیت های مبدل های صفحه ای

تولید پلیت های مبدل های صفحه ای

مشاوره و طراحی

هنوز محتوایی نداریم

زبان فارسی

دامنه و هاستینگ هم باید تهیه کنیم

سطح آشناییم صفره

خودم به روز میکنم

خوبه قالب صفحه ت

Alfalaval.com مثل این
فونت طراحی سایت باشه فونت estedad

رنگ ها یه پالت باشن نه فقط یک رنگ آبی 

یک یا دو رنگ دیگه اضافه بشه
